# Tax Loss Harvesting Interface

A responsive Tax Loss Harvesting tool built with React + TypeScript + Tailwind CSS.

## Setup

```bash
bun install
bun run dev
```

Open http://localhost:5173

## Tech Stack

- Vite 5 + React 18 + TypeScript 5
- Tailwind CSS 3
- React Context + useReducer (state management)
- Vitest (unit tests)

## Features

- Pre/After Harvesting capital gains comparison
- Real-time gains update on holdings selection
- Responsive design (mobile-first)
- Select-all checkbox with indeterminate state
- View All / Show Less holdings toggle
- Skeleton loading states
- Error state with retry

## Running Tests

```bash
bun run test
```
